# Ононская впадина — аналитическая справка (PDF)

- `Ононская_впадина_справка_мобильная.pdf`: вертикальная версия для телефона (38 страниц 9:16). Заголовки и цифры набраны Akzidenz-Grotesk Pro Bold, мелкий текст увеличен в 1,5 раза.
- `Ононская_впадина_аналитическая_справка.pdf`: исходная альбомная версия (20 полос 16:9).

Как пересобрать: положите шрифты в `src/fonts/` (`NG.otf`, `NGi.ttf`, `AG.otf`, (Adlery больше не используется)
в репозиторий не добавлены из-за лицензии), затем выполните `cd src && bash render_m.sh` (мобильная версия) или `bash render.sh` (альбомная)
(нужны Chromium и PyMuPDF).
