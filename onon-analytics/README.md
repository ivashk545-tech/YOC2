# Ононская впадина — аналитическая справка (PDF)

`Ононская_впадина_аналитическая_справка.pdf`: 20 полос 16:9, свёрстаны по исходной справке (.docx).

Как пересобрать: положите шрифты в `src/fonts/` (`NG.otf`, `NGi.ttf`, `AdleryPro.ttf`, `AdlerySwash.ttf`,
в репозиторий не добавлены из-за лицензии), затем выполните `cd src && bash render.sh`
(нужны Chromium и PyMuPDF).
